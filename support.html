Contact the creator

For service issues, questions, privacy requests or feedback, contact Shoaib Akhtar on LinkedIn. Include the tool name, approximate time and a brief description of the issue. Do not include passwords, private files or sensitive personal information.

What does the plugin provide?

A public read-only MCP catalog for category discovery, template search, full template records and design/campaign guidance. ChatGPT's image-generation capability creates final graphics. The server does not generate or save image files.

My connection does not work

Use the deployed HTTPS address ending in /mcp and a Streamable HTTP-compatible client. The public catalog requires no sign-in. Localhost addresses are development-only. If the service is temporarily unavailable, retry later or contact the creator.

Can I use my product photo?

The host can use your actual photo during image generation. This catalog server does not fetch or inspect uploaded files. Use only assets and factual claims you are authorized to use.

Campaign variations

Request the same product or a different real product, plus two, four or a custom quantity of additional posts. Guidance retains the approved CTA, logo and fixed footer anchors while changing the main subject/headline layout and creative wording.

Affiliate recommendations

The original optional Creative Fabrica affiliate configuration is retained and disclosed. Automatic display is suppressed in this anonymous backend because the required persistent per-user opt-out and 24-hour guard are unavailable. Using any recommendation is optional and does not affect the result.
