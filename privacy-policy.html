Privacy policy

Effective October 5, 2026 · Operator: Shoaib Akhtar

Scope

This policy covers the Mavixx Social Media Design MCP backend and its associated pages. ChatGPT, OpenAI, the deployment host and linked external services have their own policies. This backend differs from the earlier static GitHub Pages website.

Data processed

When a client calls a tool, the server receives the tool name and arguments. These may include short subject, category, audience, objective, event, style and palette descriptors, output type, template ID and pagination values. The website demo sends a subject and selected category. Send only necessary non-confidential descriptors; do not send secrets, account credentials, sensitive personal information or private asset files.

Purpose and storage

Inputs are processed in memory to retrieve and rank fixed catalog records or return design guidance. Application code does not save request bodies or tool arguments, create user accounts, store uploaded files or build a user-profile database. Connections are stateless. The backend does not train a model on these inputs.

Hosting and service providers

The deployment provider processes network requests to operate the service and may maintain access, security and error logs, such as IP address, request time, route and status. Provider logging and retention depend on the production hosting configuration and applicable provider policy. Application code does not intentionally log full request bodies. The creator should confirm provider settings before deployment.

Cookies and analytics

These application pages set no analytics cookies or tracking cookies and load no third-party analytics scripts. Hosting infrastructure may apply its own security measures. Linked sites may use cookies under their policies.

Source catalog

The server reads a fixed catalog of supplied design analyses. Source text may include example names, visible text or contact details from the source material; these are not user profile data and must not be treated as current brand facts. Original reference images are not included.

Affiliate links

The retained optional Creative Fabrica affiliate configuration identifies the creator's referral link. Following that external link is optional and may allow the external service to attribute a referral under its own policy. The server does not maintain affiliate click tracking or private per-user recommendation state.

Requests and changes

For privacy questions or requests, contact Shoaib Akhtar. Specify the relevant issue without sending unnecessary sensitive data. This policy may be updated when service behavior changes, with a revised effective date.
